# Общая выгрузка Jarvis в Google Таблицы

После настройки сотруднику нужен только общий PIN. Адрес Apps Script и его код доступа хранятся в секретах Cloudflare Worker; в браузер они не передаются. PIN открывает выгрузку на 12 часов в этом браузере.

## Однократная настройка администратором

1. В целевой таблице откройте «Расширения → Apps Script». Замените код файлом `public/jarvis-apps-script.gs` из репозитория и сохраните его.
2. В Apps Script выберите «Развернуть → Управление развертываниями», откройте текущее веб-приложение, нажмите редактирование и создайте новую версию. Оставьте запуск от своего аккаунта и доступ «Все». Если веб-приложение ещё не создавали — создайте его с этими же параметрами.
3. Скопируйте адрес веб-приложения, заканчивающийся `/exec`. В целевой таблице обновите страницу, откройте меню «Jarvis → Показать код доступа» и скопируйте код.
4. В Cloudflare откройте Workers & Pages → `jarvis-warehouse` → Settings → Variables and Secrets. Добавьте следующие значения именно как **Secret**, затем нажмите Deploy:

   | Имя секрета | Значение |
   | --- | --- |
   | `JARVIS_APPS_SCRIPT_URL` | Скопированный адрес Apps Script `/exec` |
   | `JARVIS_APPS_SCRIPT_TOKEN` | Код из меню «Jarvis → Показать код доступа» |
   | `JARVIS_EXPORT_PIN` | Общий пароль/PIN для сотрудников; используйте не менее 12 случайных символов |
   | `JARVIS_EXPORT_SESSION_SECRET` | Случайный секрет подписи сессий, не менее 32 символов |

   Секрет подписи можно сгенерировать на своём компьютере командой:

   ```powershell
   node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))"
   ```

   Не помещайте эти значения в Git, обычные Worker Variables, исходный код или общий чат. Для локального теста используйте файл `.env.local`, который не следует добавлять в Git.

5. Передайте сотрудникам только `JARVIS_EXPORT_PIN`. В Jarvis они вводят его у блока выгрузки; адрес Apps Script и его код доступа сотрудникам не нужны.
6. Нажмите «Проверить связь» и убедитесь, что Jarvis видит шаблон. Затем выполните первую выгрузку и проверьте созданную таблицу в папке отчётов.

Каждая новая книга направлений получает доступ «Все, у кого есть ссылка — Редактор». На городских вкладках строки с товарами имеют высоту 150 px; строки ниже отчёта и столбцы правее таблицы скрыты. На сводке скрываются строки и столбцы вне заполненной таблицы.

`wrangler.jsonc` настроен сохранять значения, добавленные через Cloudflare Dashboard, при следующих автодеплоях.

## Ограничения и безопасность

- PIN не сохраняется в localStorage. После проверки сервер выдаёт HttpOnly-cookie с ограниченным сроком действия; выход отзывает сессию в текущем браузере.
- Частота проверки PIN ограничена 100 попытками в минуту на IP, а записи в Google — 20 запросами в минуту на IP. Лимиты Cloudflare работают отдельно в каждой точке обработки запросов.
- Apps Script должен быть опубликован с актуальным кодом из репозитория: новая серверная интеграция ожидает JSON-ответ, который добавлен в `doPost`.
- Для открытия созданных файлов сотрудникам также нужны права на папку Google Drive. Права на саму таблицу-шаблон автоматически не меняются.
- Ссылка на созданную книгу позволяет любому её обладателю редактировать все вкладки отчёта. Не размещайте эту ссылку в публичных местах.
